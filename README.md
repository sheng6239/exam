# 👟 美美小香腳 — 智慧除濕烘乾鞋架

## 📖 專題介紹

本專題使用 **STM32 NUCLEO-G474RE 開發板**，設計一套「智慧除濕烘乾鞋架」控制系統。

主要目的是模擬鞋架偵測潮濕狀態、提醒使用者，以及啟動烘乾功能的操作流程，透過 LED 燈號顯示目前系統狀態，並使用 PWM 控制模擬烘乾輸出。

本專題結合 GPIO、外部中斷（EXTI）、按鈕去彈跳、PWM、非阻塞計時及有限狀態機（FSM），實現完整的嵌入式控制流程。

## 🎯 專題目標

- 模擬鞋架的潮濕偵測與提醒功能。
- 透過按鈕切換系統狀態。
- 使用不同顏色的 LED 顯示目前運作模式。
- 利用 PWM 模擬烘乾功能與輸出強度控制。
- 使用非阻塞計時方式管理烘乾時間。
- 透過按鈕去彈跳，避免重複觸發造成誤判。

## 🚦 系統狀態說明

系統使用有限狀態機（Finite State Machine，FSM）管理三種主要狀態。

| 狀態 | LED 顯示 | 功能說明 |
|---|---|---|
| SAFE（安全） | 🟢 綠燈 | 系統待機，表示正常狀態 |
| WET_WARN（潮濕警告） | 🔴 紅燈 | 模擬偵測到潮濕，提醒使用者 |
| DRYING（烘乾中） | 🟡 黃燈、🔵 藍燈 PWM | 啟動模擬烘乾功能 |

## 🔄 系統操作流程

1. 系統啟動後，預設進入 **SAFE** 狀態，綠燈亮起。
2. 按下潮濕模擬按鈕 **PC6**，進入 **WET_WARN** 狀態，紅燈亮起。
3. 按下啟動按鈕 **PC9**，進入 **DRYING** 狀態，黃燈亮起並啟動藍燈 PWM。
4. 正常烘乾時間設定為 **40 分鐘**，時間結束後自動返回 SAFE。
5. 烘乾過程中可按下 PC9，提前停止並返回 SAFE。
6. 按下 **PC8** 可進行展示模式，讓 PWM 在約 3 秒內逐漸降低至 0%，再返回 SAFE。
7. 按下開發板的 **B1 按鈕（PC13）**，可重設系統並返回 SAFE。

## 🔌 GPIO 腳位配置

| 腳位 | 功能 |
|---|---|
| PA12 | 綠色 LED：安全狀態 |
| PB12 | 紅色 LED：潮濕警告 |
| PA11 | 黃色 LED：烘乾狀態 |
| PB2 | 藍色 LED：PWM 輸出 |
| PC6 | 模擬潮濕狀態切換 |
| PC8 | PWM 漸弱展示 |
| PC9 | 啟動／停止烘乾 |
| PC13 | 開發板 B1：系統重設 |

## 💡 技術特色

### 1. 有限狀態機（FSM）

透過 SAFE、WET_WARN、DRYING 三種狀態管理系統行為，使程式流程清楚，避免不同功能互相衝突。

### 2. 外部中斷（EXTI）

利用外部中斷偵測 PC6、PC8、PC13 的按鈕事件，提高系統對輸入的反應能力。

### 3. 按鈕去彈跳（Debounce）

使用約 50 ms 的去彈跳判斷，減少機械按鈕彈跳造成的重複觸發。

### 4. PWM 控制

使用 TIM5_CH1 產生 PWM 訊號，頻率約為 **1 kHz**，烘乾模式初始占空比為 **20%**，並支援漸弱效果展示。

### 5. 非阻塞計時

使用 `HAL_GetTick()` 管理烘乾時間及漸弱效果，避免長時間延遲影響其他按鈕操作。
